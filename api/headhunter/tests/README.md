# Тестовые скрипты парсера HeadHunter

Эта папка содержит тестовые скрипты для проверки работы парсера HeadHunter без использования Celery.

## Доступные тесты:

### `test_parser.py`
Простой тест парсинга вакансий по текстовому запросу.
- Парсит вакансии по запросу "Python" 
- Показывает статистику результатов
- Используется для базовой проверки работы парсера

### `test_parser_examples.py`
Множественные сценарии парсинга с разными параметрами:
- Парсинг по нескольким запросам
- Быстрый режим без деталей
- Универсальный парсинг по регионам

### `test_tech_parser.py`
Тестирование генератора поисковых запросов на основе технологий:
- Генерация запросов по топ-технологиям
- Тестирование работы с алиасами
- Проверка категорий технологий
- Статистика по технологиям

## Запуск тестов:

```bash
# Из директории ergo_ms/api
python src/modules/vacancies_parser/headhunter/tests/test_parser.py
python src/modules/vacancies_parser/headhunter/tests/test_parser_examples.py
python src/modules/vacancies_parser/headhunter/tests/test_tech_parser.py
```

## Примечание:

Эти скрипты предназначены для разработки и отладки. Для продакшн использования рекомендуется использовать Celery задачи через management команды.
